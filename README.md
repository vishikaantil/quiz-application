# Full Stack Interactive Quiz Application

Created by: Vishika

A full-stack web application for taking interactive quizzes, managing scores, viewing leaderboards, and tracking user performance.

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Backend**: Java 17, Spring Boot 3, Spring Data JPA
- **Database**: MySQL
